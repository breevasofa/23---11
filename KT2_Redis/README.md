# КТ2: организации в Redis HASH

Источник: [data_УК.xlsx](https://github.com/junaart/ForStudents/raw/refs/heads/main/Big_Data/data_%D0%A3%D0%9A.xlsx).

Программа `solution.py` отбирает строки, где `Выдано предписаний > 10`. Каждую организацию она сохраняет в Redis с ключом, равным **полному названию организации**. Значение ключа — хэш ровно из двух полей:

| Поле Redis | Столбец Excel |
| --- | --- |
| `Выдано предписаний` | `Выдано предписаний` |
| `Сумма штрафов` | `Сумма штрафа (тыс. руб.)` |

Код проверяет число выбранных организаций, все ключи Redis, тип `hash` и оба значения каждого хэша. GitHub Actions выполняет программу с Redis, проверяет результат через `redis-cli` и сохраняет снимок базы `organizations.rdb`, который можно загрузить в Redis повторно.

В исходном Excel — 32 007 строк, условию соответствуют 1 343 организации. `redis-cli` подтвердил 1 343 ключа, тип `hash` и два поля у проверенного примера.
