# Анализ показателей Titanic

Источник: датафрейм `seaborn.load_dataset("titanic")`, 891 пассажир и 15 исходных столбцов. Для запуска без сети сохранён [исходный CSV](titanic.csv) из [seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv). Код сначала пытается загрузить датафрейм через seaborn, затем использует локальную копию.

## Множества W и P

| Вариант | Результативные признаки W | Показатели P |
| --- | --- | --- |
| 1 | `survived`, `age` | `pclass`, `sex`, `sibsp`, `parch`, `fare`, `embarked`, `deck` |
| 2 | `survived`, `sex` | `pclass`, `age`, `sibsp`, `parch`, `fare`, `embarked`, `deck` |

Из P удалены повторяющие или производные признаки: `alive` повторяет `survived`; `class` — `pclass`; `embark_town` — `embarked`; `who` и `adult_male` вычисляются по `sex` и `age`; `alone` — по `sibsp` и `parch`. Такое исключение особенно важно, когда `survived` или `sex` находятся в W.

## Метод

Каждый результативный признак оценивается отдельно. Для каждого показателя P строится простая модель по **одному** признаку: среднее значение целевого признака в группах, сглаженное пятью наблюдениями со средним обучающей выборки. Для количественных `age` и `fare` используются интервалы; интервалы `fare` определяются только на обучающей части. Применяется пятиблочная перекрёстная проверка с `seed=42`; для бинарных целей блоки стратифицированы.

В таблицах указано сокращение среднеквадратичной ошибки относительно прогноза средним обучающей выборки, в процентах. Для `survived` и `sex` это сокращение Brier score. Чем больше процент, тем полезнее признак для одиночного прогноза. Отрицательное значение означало бы результат хуже базового. Это **предсказательная связь, а не причинное влияние**. Взаимодействия и взаимосвязь признаков между собой модель не учитывает. Направление связи описывается наблюдаемыми долями или средними по группам.

Пропуски в P выделены в отдельную группу; строки с пропущенным целевым значением исключены. У `age` отсутствуют 177 значений, у `deck` — 688. Поэтому выводы о палубах ограничены и могут отражать доступность сведений о каюте и класс билета.

## Вариант 1

### Выживание `survived`

| Место | P | Снижение ошибки | Направление наблюдаемой связи |
| ---: | --- | ---: | --- |
| 1 | `sex` | 29,2 % | Женщины выживали чаще: 74,2 % против 18,9 % у мужчин. |
| 2 | `pclass` | 10,7 % | В 1 классе выжили 63,0 %, в 2 — 47,3 %, в 3 — 24,2 %. |
| 3 | `fare` | 10,1 % | В верхней пятой части тарифов выжили 62,1 %, в нижней — 21,7 %. |
| 4 | `deck` | 9,7 % | При известной палубе доля выживших обычно выше; у 688 пассажиров палуба неизвестна. |
| 5 | `sibsp` | 2,8 % | При одном сопровождающем супруге или сиблинге выжили 53,6 %, без них — 34,5 %. |
| 6 | `embarked` | 2,4 % | Cherbourg: 55,4 %, Southampton: 33,7 %, Queenstown: 39,0 %. |
| 7 | `parch` | 2,1 % | При одном родителе или ребёнке выжили 55,1 %, без них — 34,4 %. |

Главный одиночный показатель для выживания в варианте 1 — `sex`. `fare` и `pclass` связаны между собой, поэтому их эффекты нельзя складывать.

### Возраст `age`

| Место | P | Снижение ошибки | Направление наблюдаемой связи |
| ---: | --- | ---: | --- |
| 1 | `pclass` | 13,5 % | Средний возраст: 1 класс — 38,2 года, 2 — 29,9, 3 — 25,1. |
| 2 | `parch` | 10,7 % | При 0 родителях или детях — 32,2 года, при 1 — 24,4, при 2 — 17,2. |
| 3 | `sibsp` | 8,5 % | При 0 супругах или сиблингах — 31,4 года; при 4 — 7,1 года. |
| 4 | `deck` | 7,2 % | Различия по палубам есть, но известно лишь 184 возраста с указанной палубой. |
| 5 | `fare` | 2,7 % | Более высокая плата в среднем связана с более старшим возрастом, связь слабая. |
| 6 | `sex` | 0,8 % | Средний возраст женщин — 27,9 года, мужчин — 30,7. |
| 7 | `embarked` | 0,2 % | Порт посадки почти не помогает предсказать возраст. |

Главный одиночный показатель для возраста — `pclass`. Увеличение `parch` и `sibsp` часто связано с присутствием детей, но маленькие группы с большими значениями этих счётчиков нельзя интерпретировать как общую монотонную зависимость.

## Вариант 2

### Выживание `survived`

| Место | P | Снижение ошибки | Направление наблюдаемой связи |
| ---: | --- | ---: | --- |
| 1 | `pclass` | 10,7 % | 1 класс: 63,0 %; 3 класс: 24,2 %. |
| 2 | `fare` | 10,1 % | Верхняя пятая часть тарифов: 62,1 %; нижняя: 21,7 %. |
| 3 | `deck` | 9,7 % | При известной палубе выживаемость выше; 688 пропусков. |
| 4 | `sibsp` | 2,8 % | Один сопровождающий: 53,6 %; ни одного: 34,5 %. |
| 5 | `embarked` | 2,4 % | Cherbourg: 55,4 %; Southampton: 33,7 %. |
| 6 | `parch` | 2,1 % | Один родитель или ребёнок: 55,1 %; ни одного: 34,4 %. |
| 7 | `age` | 1,9 % | До 5 лет: 70,5 %; старше 60: 22,7 %; 177 пропусков возраста. |

Когда `sex` перенесён из P в W, на первое место для прогноза выживания выходит `pclass`. Значение 10,7 % меньше, чем 29,2 % для `sex` в варианте 1; это разные наборы доступных показателей.

### Пол `sex`

Для бинарной цели 1 означает `female`, поэтому направление в таблице — доля женщин.

| Место | P | Снижение ошибки | Направление наблюдаемой связи |
| ---: | --- | ---: | --- |
| 1 | `fare` | 6,9 % | В верхней пятой части тарифов женщины составляют 51,6 %, в нижней — 20,5 %. |
| 2 | `parch` | 5,6 % | При `parch=0` женщин 28,6 %, при `parch=1` — 50,8 %. |
| 3 | `sibsp` | 4,0 % | При `sibsp=0` женщин 28,6 %, при `sibsp=1` — 50,7 %. |
| 4 | `deck` | 2,4 % | Связь слабая и ограничена большим числом пропусков. |
| 5 | `pclass` | 1,6 % | В 1 классе женщин 43,5 %, в 3 — 29,3 %. |
| 6 | `embarked` | 1,2 % | Небольшие различия между портами. |
| 7 | `age` | 0,9 % | Возраст слабо помогает определить пол. |

Для пола самый полезный одиночный предиктор в P — `fare`, но даже он даёт лишь 6,9 % сокращения ошибки. Нельзя утверждать, что тариф или число родственников *вызывает* пол пассажира: таблица показывает состав пассажиров в группах.

## Запуск в GitHub Codespaces

```bash
python -m pip install -r titanic_w_p/requirements.txt
python titanic_w_p/analysis.py
```

Откройте `titanic_w_p/analysis.ipynb` и выполните ячейки сверху вниз. Полные воспроизводимые числовые результаты записываются в `results.json`.
