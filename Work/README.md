# Лабораторная работа №1

Все действия с текстовыми файлами выполняются командами терминала в [`reproduce.sh`](reproduce.sh), без текстового редактора. Для повторения задания в Linux запустите `bash reproduce.sh` из этого каталога. Сценарий перезаписывает исходные текстовые файлы; данные о ядре и дату добавляет в конец `Result_3`.

`Result_two` содержит строки файла `Text @1` в обратном порядке. `Result_3` содержит полный вывод `uname -a` и текущую дату.

Права каталогов задаются в конце сценария: `chmod 772 'Лабораторная работа №1!'` и `chmod 200 'ФИО'`. Git не хранит права каталогов, поэтому после клонирования репозитория примените их запуском сценария. На Windows права `chmod` не совпадают с правами POSIX; точные режимы проверяются в Linux через `stat -c '%a %n' */`.
